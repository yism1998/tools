# Tools 工具箱

浏览器本地工具箱，通过顶部标签切换工具。目前提供「水印清除」，直接打开或刷新 `#/watermark` 可进入该工具。

在浏览器中涂抹并清除图片水印。图片读取、选区编辑和清除处理均在本机完成，图片不会上传到服务器。

## 功能

- **图片管理**：支持选择或拖入 PNG、JPG、WebP 图片；点击图片右上角的 × 可清空图片和编辑记录，重新上传。
- **选区编辑**：使用可调大小的圆形画笔覆盖水印，支持擦除选区、清空选区和撤销。
- **缩放与拖动**：触屏支持双指缩放、双指拖动，移动工具支持单指拖动；PC 支持鼠标滚轮缩放、移动工具、空格拖动和鼠标中键拖动。
- **水印清除**：涂抹后点击「清除水印」开始处理，显示模型加载和处理进度，支持主动取消与失败重试。
- **结果查看**：支持原图对比、继续涂抹处理和 PNG 导出。
- **桌面安装**：支持 PWA，可通过「安装到桌面」入口，在兼容的浏览器中安装为独立窗口应用。
- **离线使用**：页面、模型及运行文件缓存完整且未被浏览器清理时，可以离线打开并处理图片。

## 实现原理

### 本地清除

应用使用 Vue 3 构建编辑界面，通过 Canvas 保存图片与涂抹选区。LaMa 模型由 ONNX Runtime Web 的 WASM 后端在独立 Worker 中运行，避免推理直接阻塞界面。

处理时提取选区及周围背景，将局部图像适配至 512 × 512 后交给模型预测。结果只回填选区内的 RGB 像素，保留选区外像素及图片透明度。

### 模型按需加载

首次点击「清除水印」才加载约 208 MB 的模型及所需运行文件，缩放和拖动不会触发模型下载。模型通过浏览器 Cache Storage 缓存，后续处理复用已加载的模型与推理会话；缓存不可用时仍可联网加载。

### 手势与编辑状态

双指操作根据两指间距调整缩放比例，根据两指中点变化移动画布。第二指落下时撤回当前手势的临时涂抹，避免把缩放误识别为画笔操作；需要松开双指再重新落指，才会恢复单指涂抹。

删除图片或取消处理会停止对应 Worker。旧任务回调不会覆盖新图片，超时或处理失败时保留选区，方便重试。

### 桌面安装与离线缓存

Web App Manifest 定义应用名称、图标、启动地址与独立窗口模式。支持原生安装提示的浏览器可直接弹出安装窗口，其他浏览器显示相应的安装引导。

同一个 Service Worker 同时负责页面资源缓存和跨源隔离：页面导航优先联网，断网时读取缓存页面；脚本、样式、图标等应用资源按版本缓存，WASM 运行文件在首次使用后缓存。模型由推理 Worker 单独缓存，安装应用不会提前下载模型，也不会缓存用户上传的图片。

Service Worker 为同源 GET 响应补充跨源隔离响应头，浏览器支持时启用最多 4 个 WASM CPU 线程，否则回退为单线程。跨域请求与 POST 请求使用浏览器默认网络处理。

应用更新等待现有窗口关闭，不会强制刷新正在编辑的图片；启用新版本时只清理本应用的旧页面缓存，保留模型缓存。

## 处理范围

- 工作图片长边最多 4096 像素、总像素最多 800 万，超出时自动缩小。
- 撤销记录最多保留 8 步。
- 涂抹不限时；单次清除最多等待 5 分钟，包含模型下载时间，超时后保留选区。
- 清除区域由模型生成，不保证恢复真实原图；大面积水印及文字、人脸、产品细节等区域需要检查处理效果。
